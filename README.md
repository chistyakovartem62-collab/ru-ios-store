# RU iOS Store — стартовый проект

Мини-магазин приложений внутри Telegram. Включает Telegram-бота, Mini App, каталог на SQLite и защищённые API-методы для добавления/скрытия карточек.

## Что нужно
- Python 3.11+
- HTTPS-хостинг для Mini App (например, любой VPS или PaaS с HTTPS)
- Telegram-бот, созданный через @BotFather

## Запуск локально
1. Создайте виртуальное окружение и установите зависимости:
   `python -m venv .venv`
   `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Запустите сайт: `uvicorn app:app --host 0.0.0.0 --port 8000`
4. Для теста откройте `http://localhost:8000`. Telegram Mini App в реальном Telegram требует HTTPS.
5. В отдельном терминале запустите бота: `python bot.py`.

## Настройка BotFather
1. В Telegram откройте https://t.me/BotFather и отправьте `/newbot`.
2. Укажите имя `RU iOS Store` и свободный username, заканчивающийся на `bot`.
3. Скопируйте токен в `BOT_TOKEN` файла `.env`. Никому его не отправляйте.
4. Разместите сайт на HTTPS-хостинге и укажите полный адрес с `/` в `WEBAPP_URL`.
5. В BotFather выполните `/setmenubutton`, выберите бота, задайте текст `Открыть каталог` и URL Mini App.
6. Перезапустите `python bot.py`.

## Добавление приложения
POST `/api/admin/apps` с заголовком `X-Admin-Key`:
```json
{
  "name": "Название",
  "category": "Полезные приложения",
  "description": "Краткое описание",
  "url": "https://official.example/",
  "developer": "Разработчик",
  "icon": "📱"
}
```
Пример:
`curl -X POST https://ВАШ-ДОМЕН/api/admin/apps -H "Content-Type: application/json" -H "X-Admin-Key: ВАШ_ADMIN_KEY" -d '{"name":"Пример","category":"Полезные приложения","description":"Описание","url":"https://example.com/","developer":"Разработчик","icon":"📱"}'`

Скрыть карточку: `DELETE /api/admin/apps/ID` с тем же заголовком.

## Важно о безопасности и распространении
- Не публикуйте `.env`, BOT_TOKEN или ADMIN_KEY.
- Используйте только HTTPS и официальные ссылки разработчиков.
- Начальный каталог содержит демонстрационные ссылки на официальные сайты, а не гарантированные ссылки на установку iOS-приложений.
- Не распространяйте IPA, корпоративные сертификаты, профили конфигурации или обходы ограничений Apple без разрешения и надлежащего основания.
- Для реального публичного запуска добавьте авторизацию администратора, резервное копирование, журнал изменений, rate limiting и проверку Telegram `initData` на сервере. Этот starter оставляет каталог публичным, а операции администратора защищает секретным ключом.
